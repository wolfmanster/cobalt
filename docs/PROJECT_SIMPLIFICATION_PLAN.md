# Cobalt 项目简化计划

## 目标

降低 Android 客户端、iOS PWA、远程服务端和上游 Cobalt Web 之间的重复维护成本；保留现有下载与归档行为，分阶段收敛实现边界。

## 当前约束

- `apps/client/` 是仓库内 Android 客户端的 React 实现，也是浏览器客户端的候选主线。
- `web/` 是上游 Cobalt 的 Svelte 站点，继续独立维护。
- `pwa-26e934d7/` 是当前未跟踪的完整项目快照，包含 PWA 工作和与根目录重复的项目文件。先比对、迁移独有改动，再清理副本；迁移完成前不删除或覆盖。
- `apps/server/` 已有 Node 下载队列和历史存储；Android 仍有 Room 本地归档。Android 旧归档已确定采用一次性导入；共享归档、认证和 HTTPS 入口尚未实现，单一账户与外网域名仍是待确认的部署假设。
- 现有改动 `web/src/lib/settings/defaults.ts`、`docs/GROK_IOS_PWA_HANDOFF_CN.md` 以及 PWA 快照均保留。

## 分阶段计划

### 1. 收敛平台能力边界（已完成）

- 把 Android/浏览器能力定义集中到 `apps/client/src/platform.ts`。
- 数据 API 依据“使用本地归档”选择 Capacitor 或 HTTP；平台专属布局依据 Android 平台能力；登录入口依据 X 登录能力。
- 保持行为不变，先做窄范围重构。

### 2. 确立唯一客户端源头

进度：PWA 客户端和服务端源码已迁入根目录主线；快照仍保留，待回归通过后再清理。

- 以 `apps/client/` 作为 Android 与 PWA 共用的 React 客户端主线；`web/` 保持上游站点用途。
- 对 `pwa-26e934d7/` 做路径与内容差异清单，只迁移 PWA 独有且仍需的代码/资源。
- 确认构建入口和部署说明指向主线后，再移除重复快照。

快照审计（2026-11-25）：

- `apps/client/` 主目录有 36 个文件；快照有 49 个，共有路径中 27 个内容不同，并多出 13 个 PWA 文件（Manifest、Service Worker、注册/更新逻辑和 PWA 浏览器验收脚本）。
- `apps/server/` 主目录有 17 个文件；快照有 28 个，共有路径中 14 个内容不同，并多出 11 个归档查询、分类、媒体流、HTTP API、X 解析与会话模块。
- `web/` 的 334 个共同文件中 281 个内容不同；`api/` 的 90 个共同文件全部不同；`packages/` 的 9 个共同文件全部不同。它们不能整目录覆盖，后续只考虑 PWA 必需的应用代码。
- 因此，先以仓库根目录为维护主线，逐项挑选仍需的 PWA 增量；快照继续保留，直到确认增量已经并入并完成回归。

### 3. 收敛归档 API

进度：浏览器 HTTP API 与服务端路由已接入；尚未运行构建和回归验证。

- 让客户端使用一组稳定的归档操作，由 Android 本地适配器和浏览器 HTTP 适配器分别实现。
- 先补齐服务端搜索、作者、分类、媒体 URL 和健康检查接口，再切换浏览器调用。
- 保留 Android Room 行为，直到远程归档、认证和导入流程完成验收。

已迁入搜索、作者、分类与分类分配接口、健康检查、可恢复 SSE、Range 媒体流和加密 X 会话存储。Android 继续使用本地 Capacitor 归档；浏览器使用 Node 服务端。服务端默认只监听回环地址，部署说明要求用私有访问控制保护整站及 `/api`。

### 4. 统一队列和历史的权威来源

- 认证、访问控制、远程持久化和可恢复迁移准备好后，再将 Android 与 iOS PWA 切到共享服务端归档。
- 将 Room 历史与媒体作为可重复检查的一次性迁移来源；服务端确认完整前不删除本地数据。
- 先确认单一账户、域名和外网访问方式，再编写部署与安全默认值。

### 5. 减轻首页状态负担

进度：已将队列与历史分页提取到 `apps/client/src/hooks/useJobs.ts`，分类归档状态提取到 `useCategories.ts`，X 会话流程提取到 `useXSession.ts`，服务健康、网络状态和 PWA 更新提示提取到 `useRuntimeStatus.ts`。页面导航、交互弹层和表单状态仍留在 `App.tsx`。

- 等 API 边界稳定后，把队列刷新、归档/分类、设备会话和运行状态按职责提取为少量 hooks。
- 保留已有组件划分，避免为了拆文件而拆成大量小组件。

## 本轮开始项

PWA 客户端与服务端代码已从快照并入根目录；没有搬入快照测试、构建产物或上游 `web/`、`api/` 副本。浏览器媒体保存回调现传递服务端 `downloadUrl`。队列/历史、分类/归档、X 会话及运行状态已分别提取为 hooks。尚未运行构建或回归，也尚未切换 Android 到远程归档；远程共享的认证和部署前提确认后再推进。
